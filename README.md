# ChessJS ♟️

Um jogo de xadrez feito com HTML, CSS e JavaScript, criado como projeto de estudo.

## Sobre o projeto

Este é um projeto pessoal com o objetivo de aprender e praticar lógica de programação através da implementação das regras do xadrez, além de desenvolver habilidades de front-end.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- [ ] Posicionamento inicial das peças
- [ ] Movimentação das peças
- [ ] Validação de movimentos
- [ ] Detecção de xeque
- [ ] Detecção de xeque-mate
